# ADR-0003: Scope of v0.1

- **Status:** Accepted
- **Date:** 2026-11-23
- **Plan reference:** Phases 1 to 4 in [docs/plan.md](../plan.md)

## Context

V3 set v0.1 as block choropleth, H3 toggle and UPZ panel. Since then the atlas gained a second producer and Etapas, and the public map needs to show where each number comes from.

## Decision

v0.1 includes:

- layer panel grouped by theme (Población, Red vial, Contexto)
- inspect panel on click, with values, units and field names
- information panel per layer: description, method, sources, vigencia, licence
- swipe compare between two layers (desktop)
- ES/EN switch and URL state
- for population: block choropleth, H3 toggle and UPZ/UPL panel (from V3)

Not in v0.1: charts, year slider, downloads and citation panel, scenarios.

## Alternatives considered

- **Downloads and citation in v0.1:** useful, but the release page already gives both; added after v0.1.

## Consequences

- Each panel leaves room for a chart, so adding charts later needs no layout change.
